# Contributing

Thank you for considering a contribution to ItemLocus. The project is in planning, and documentation, issue reports, and careful discussion of privacy and accessibility are the most useful help right now. Application code is not being accepted yet because it does not exist.

Please read [README.md](README.md), [docs/PRIVACY.md](docs/PRIVACY.md), and [docs/ROADMAP.md](docs/ROADMAP.md) first.

## What we ask

- Keep the project generic and public. Do not commit household-specific paths, names, addresses, hostnames, IP addresses, camera inventories, or anyone's photographs.
- Do not include images of faces, people, medicine or related gear, nudity, identity documents, or other private material — not even as examples. Prefer words, or a simple mermaid diagram, over pictures.
- Use respectful language about dementia, memory loss, aging, and disability.
- Prefer local, inspectable approaches over cloud defaults.
- Open a pull request against the default branch with a completed [pull request template](.github/pull_request_template.md).

## Developer Certificate of Origin (sign-off)

Each commit must include a sign-off in the commit message:

    Signed-off-by: Your Name <your-identifier>

Use a name and identifier you are comfortable making public. A GitHub username is fine. You do not have to use an email address if you prefer not to.

The sign-off is a [Developer Certificate of Origin](https://developercertificate.org/) style statement: you certify that the contribution is yours to submit, and that you agree to the contributor terms above. Add it with `git commit -s` when you have a `user.name` and `user.email` (or equivalent) configured, or write the `Signed-off-by` line yourself.

Pull requests should also complete the agreement checkbox in the pull request template.
